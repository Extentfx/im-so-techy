## Findings from this review (all fixed)

1. **Phone Shortcut sleep import would have been blocked** by the cross-site rule, because Shortcuts send no browser headers. Fixed narrowly (one route, service-token header required) with tests that the exemption does not leak to any other route.
2. **Email summaries could store sensitive numbers.** A short email's whole body fits in a summary, so an account number could be stored. Summaries now redact long digit strings, email addresses and long codes.
3. **One page crashing took down the whole app** (found by the end-to-end run). Pages now sit inside an error boundary, so the rest of the app and the page selector keep working.
4. **Errors vanished instantly** on several pages because a reload cleared them, hiding failures such as "bad address". Messages now persist briefly and clear themselves.
5. **Low-contrast buttons** (white on the accent colour, and light buttons on dark panels) failed WCAG AA. Colours darkened; the accessibility scan now reports none.

## Accepted risks and limits

- **The family link is a deliberate public route.** It is protected only by a 256-bit random token that expires (1 to 30 days) and can be revoked at once; only a hash is stored; every failure returns the same 404. It shows school, family and Dashboard events only. It has no rate limit of its own, which is acceptable for an unguessable token but worth knowing. Don't share it somewhere public.
- **There is no general API rate limit.** The Access login is the gate. Device actions and Claude spend are rate limited because they have real-world cost.
- **ntfy notifications travel through ntfy.sh.** The topic is encrypted at rest and acts like a password; anyone who learns it can read your notices. Titles and messages contain schedule details.
- **Audit-log times come from the database clock**, not the request clock, so a test that fakes the clock will see real timestamps.
- **Claude and Home Assistant integrations are untested against the real services** (stand-ins only), and Cloudflare Access has not been tested end to end.
